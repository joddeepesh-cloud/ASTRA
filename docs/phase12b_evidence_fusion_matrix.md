# ASTRA Phase 12B — Evidence Fusion Matrix

## Executive Summary
This document defines the formal decision matrix for ASTRA's Evidence Fusion Engine (`backend/app/services/evidence/evidence_fusion.py`). It specifies how local image structural metrics and external multi-modal catalog evidence (Gaia, SDSS, WISE, TESS, Exoplanet Archive, Nebula datasets) are synthesized to produce scientifically justified target decisions without false precision or forced classifications.

---

## Evidence Fusion Matrix Table
